# 🎨 Color Flipper

A simple and fun JavaScript project that changes the background color of the page with each click of a button. Great for learning DOM manipulation and JavaScript basics!

## 🚀 Features

- Changes background color to a random color
- Displays the current color code on screen
- Built using only **HTML**, **CSS**, and **Vanilla JavaScript**
- Lightweight and beginner-friendly

## 💡 How It Works

When the user clicks the "Click Me" button, a random hex color is generated and applied as the background color of the page. The hex code is also displayed for the user to see.
